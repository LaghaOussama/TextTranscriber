# 🎙️ Transcriber App – Spring AI + React JS

Application full stack de transcription audio/vidéo utilisant **Spring Boot** (Spring AI) pour le backend et **React JS** pour le frontend.

## ✨ Fonctionnalités

- Upload d’un fichier audio (MP3, WAV) ou vidéo
- Transcription automatique via une IA (Spring AI)
- Affichage du texte transcrit en temps réel

## 🛠️ Stack technique

- **Backend** : Spring Boot, Spring AI, Java 17+
- **Frontend** : React JS, Axios
- **API** : REST (JSON)

## 🚀 Lancer le projet

### Backend (Spring Boot)

```
cd backend
./mvnw spring-boot:run   # ou mvn spring-boot:run
```

- Le serveur démarre sur http://localhost:8080

### Frontend (REACT)

```
 cd frontend
 npm install
 npm start
```

- L’application est accessible sur http://localhost:5173

- Configure ta clé API d’IA dans application.properties
